Whister Browser Project Privacy Policy

Effective Date: 18 October 2026

Whister is an independent web browser built for speed, transparency, and personal customization. We believe your data belongs exclusively to you. This policy explicitly documents our data minimization structures, server network boundaries, and automated update parameters.

1. Zero-Telemetry Data Collection

Unlike standard stock browsers, Whister is engineered from the ground up to eliminate baseline diagnostic reporting loop junk.

  • No Browsing History Collection: Your web search history, visited domains, and downloaded files remain entirely localized inside your local client profile tree (AppData\Local\Chromium\User Data\) and are never transmitted to our infrastructure.
  • No User Accounts: Whister does not feature profile synchronisation or authentication clouds. There is no sign-in requirement, and we do not maintain individual usage portfolios.
  • Upstream Search Controls: When utilizing the New Tab search engine routing selector panel matrix, queries are passed directly to your chosen provider (DuckDuckGo, Brave, or Google). Whister never intercepts or logs your parameters.

2. Automated Update Server Operations

To deliver automated engine patches, the internal C++ layer securely coordinates with our staging subdomain endpoints using automated version cross-checks.

  • Automated Request Payload: When checking for updates via your UI settings panel, the browser transmits a minimalist, standardized JSON string container tracking solely your current software configuration:
    {"version": "158.0.8105.0"}
  • Edge Processing Layer: This payload is analyzed strictly on the fly by Cloudflare serverless runtimes at ://whisterbrowser.com to evaluate your file needs. We do not store, log, or track your machine's physical IP address during these update verification checks.
  • Asset Distribution Security: All installation packages (mini_installer.exe) and text patch configurations are distributed via secure, HTTPS-encrypted Cloudflare R2 storage arrays.

3. Cookies and Third-Party Assets

  • Website Analytics: Our static documentation directory pages do not use third-party tracking pixels, marketing cookies, or user fingerprinting scripts.
  • External Repositories: Links pointing directly to our release installation assets are served via GitHub, which is governed independently by GitHub's corporate data provisions.

4. Compliance & Contact

Because the browser project is completely open-source, you can trace our execution network parameters line-for-line right inside our public workspace code tree repository files at any time.

For configuration inquiries or architecture tracking requests, open an issue ticket directly on the Whister project repository console page.

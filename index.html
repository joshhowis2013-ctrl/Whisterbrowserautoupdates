The Whister Project

Whister is an open-source, independent web browser fork utilizing the Chromium rendering architecture. The project focuses on user-customizable visual presentation interfaces, lightweight background source-patch distribution matrices, and reduced upstream diagnostic logging footprints.

This site is where the auto updates Will be hosted and managed for the Whister browser project.

Project Design Attributes

  • Rendering Core: Built on Chromium engine build targets.
  • Interface Structure: Native WebUI implementations featuring local skin and accent configuration selection arrays.
  • Distribution Pipeline: Local and network-delivered unified diff (.patch) tracking structures.

Building the Tree via Terminal Core

To compile your own instance tree of Whister natively, run the tracking configuration generation tools inside your workspace environment repository directory target path:

# Generate the compilation output cache workspace build arguments matrix directory files
gn gen out/Default

# Initiate the parallel compilation target processing graph
autoninja -C out/Default mini_installer

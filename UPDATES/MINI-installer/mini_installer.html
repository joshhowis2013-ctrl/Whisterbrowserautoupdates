Whister Binary Target: mini_installer.exe

This directory tracks the active deployment hosting parameters, command-line arguments, and verification metrics for the lightweight Whister browser installer stub package.

Primary Target Hosting Profile

The background package wrapper is decoupled from code repositories and delivered via high-performance cloud storage paths.

Metric Parameter Target Configuration Data / Value
Production Delivery URL https://whisterbrowser.com
Storage Layer Platform Cloudflare R2 Storage (Zero-Egress Object Storage Array)
DNS Distribution Alias CNAME record mapped through whisterbrowser.com zone file management
Target Application Payload Whister Browser (Windows 64-bit Core Binaries)

Automated Background Launch Arguments

When downloaded asynchronously by the internal C++ layer, the executable is invoked via base::CommandLine using specific parameter flags to ensure zero background interface disruption for active users:

  • /S — Instructs the underlying Nullsoft (NSIS) compilation container script to suppress all visual install wizard windows.
  • --silent — Signals the nested un-archiver logic to seamlessly deploy application file blocks directly into the local workspace layout.

Deployment Best Practices & Validation

  • Path Optimization: Always unpacks directly into the localized user profile tree path (AppData\Local\Whister).
  • Compilation Target: Generated natively via your workstation workspace terminal targets using autoninja -C out/Default mini_installer.
  • Security Cache Control: Distributed directly using your Cloudflare domain settings to force immediate HTTPS encryption loops on any connected client.
